# 备份与恢复

所有命令在英语新闻阅读库目录执行。脚本仅使用 Python 标准库，没有外部上传；只创建新文件/新目录，不删除、替换或合并现有库。

## 创建备份

```powershell
python -B -X utf8 backup.py create
```

返回一个 `backups/news-时间-唯一编号.zip` 路径和 verified=true。备份包含文件夹、原始文章、所有已提交历史版本、原始粘贴记录，以及尚未提交记录的原字节；进程 `.write-lock` 不打包。每个文件有 SHA-256 和大小清单，生成后重新校验 ZIP。

备份前验证当前及历史文章；有损坏文件时拒绝生成。备份期间发生保存或补译时会检测到版本/字节变化并拒绝，待操作结束后再新建备份。不需要停止正常阅读，不写源数据。

默认上限 256 MiB、10000 个文件。若失败留下文件，不视为有效备份；脚本不会自行清理它。备份只保留在本机，请自行选择安全的第二份保存位置。

## 验证已有备份

将下面的路径换成 create 返回的实际 ZIP 文件名：

```powershell
python -B -X utf8 backup.py verify backups/实际备份文件名.zip
```

检查文件清单、大小、哈希及路径。哈希证明清单与文件一致，不是来源签名；只使用可信来源的自己的备份。

## 恢复到独立目录

```powershell
python -B -X utf8 backup.py restore backups/实际备份文件名.zip --destination output/restore-自己选的新编号
```

目标必须不存在且位于当前项目内，父目录必须已存在。程序在写入前检查全部内容、路径穿越、符号链接和展开大小，再逐文件独占创建，最后校验全部字节、文章数量及历史版本。不能恢复到正式 data 或其子目录，不能覆盖已有恢复目录。

恢复后返回 verified=true 和实际恢复目录。可独立启动查看：

```powershell
python -B server.py --port 8767 --data-dir output/restore-自己选的新编号
```

确认端口空闲；这只是本机独立阅读服务。检查标题、译文、原始输入和版本后按 Ctrl+C 停止。

切换 MCP 到恢复库、替换正式库和删除旧库不是这个工具的动作。如果确需切换，先核对恢复结果、备份正式库，再明确授权具体配置改动；不直接搬走或覆盖 data。

## 不在文件备份里的内容

浏览器 localStorage 的阅读位置、字号与展开状态，以及 sessionStorage 未保存草稿，不属于文章文件备份。恢复库使用不同端口时这些记录也不共享。Codex 用户配置、MCP SDK和项目源码需要另外保留；ZIP 只备份 data。
